# Этап 8 — ЛР15: WSS с привязкой к пользователю

## Что сделано
- `security/SocketUserBinding.kt` (новый, чистый JVM):
  - `SocketPrincipal(userId, sessionVersion)` с проверкой формата;
  - `UserBoundSocketKeys` — из учебного мастер-ключа через HMAC выводятся отдельный ключ билетов и **отдельный ключ кадров для каждого пользователя**;
  - канал `/lab15/u/<sha256(userId)[:16]>/<uuid>` — сам userId в канал не попадает;
  - `SocketTicketCodec` — одноразовый билет рукопожатия `v1.user.version.exp.nonce.sig`, TTL 30 с, привязан к пользователю, версии сессии и конкретному каналу; передаётся заголовком `X-Lab-Ticket`, не в URL; проверка с защитой от повтора.
- `security/LocalLiveSocket.kt`: необязательный `userBinding`:
  - нет активного пользователя — нет подключения;
  - кадры подписываются и проверяются ключом текущего пользователя;
  - смена пользователя или версии сессии (выход, блокировка, повторный вход) обрывает соединение, переподключения под новым пользователем нет;
  - `onPrincipalChanged()`, метрика `boundUserTag`.
- Debug-экран ЛР15: пользователь = проверенная учебная роль + активный локальный вход (`localAuth.authenticationSnapshot()`).
- `tools/LocalLab15WssServer.java`: сервер требует валидный билет, принимает только каналы `/lab15/u/...`, проверяет кадры ключом пользователя из билета.

## Проверки

Покрыто: чужой ключ кадра, окно времени, повтор билета, другой канал, канал чужого пользователя, истёкший/слишком долгий билет, чужой мастер-ключ, подмена версии, мусор и null.
- `SocketUserBindingTest.kt` — 14 JVM-тестов (10 юнит + 4 с MockWebServer/TLS pin). **Не запускались**: в песочнице нет Gradle и Android SDK.

## Ограничения
- Мастер-ключ остаётся учебным `LOCAL_FIXTURE_KEY` debug-сборки; это не продакшн-схема выдачи ключей.
- Смена пользователя обнаруживается при следующем событии сокета (open/message/переподключение) или явным `onPrincipalChanged()`; глобальная подписка на logout не подключена.
- Если в debug включён HttpLoggingInterceptor уровня HEADERS, заголовок `X-Lab-Ticket` нужно добавить в `redactHeader`.
- Формат билета Kotlin ↔ Java проверен только сравнением кода и Java-тестом; совместный прогон приложение↔сервер не выполнялся.
