# ЛР14 — обоснование разрешений и exported-компонентов

| Разрешение | Зачем | Когда запрашивается | Что будет при отказе |
|---|---|---|---|
| `POST_NOTIFICATIONS` (API 33+) | Уведомление медиаплеера (управление воспроизведением) и учебные уведомления безопасности | Только по кнопке в ЛР14, с объяснением (rationale) и переходом в настройки при постоянном отказе | Воспроизведение работает, уведомление в шторке не показывается |
| `FOREGROUND_SERVICE` + `FOREGROUND_SERVICE_MEDIA_PLAYBACK` | `PlaybackService` (Media3) должен работать как foreground-сервис типа mediaPlayback, иначе система остановит музыку в фоне | Normal-разрешения, выдаются при установке; сервис стартует только при начале воспроизведения | — |
| `CAMERA` (camera.any — required=false) | Сканирование QR-приглашений треков | Только при открытии сканера | Можно вставить приглашение текстом |
| `INTERNET`, `ACCESS_NETWORK_STATE` | Поиск/стриминг, каталог постов, офлайн-индикация | При установке | — |
| `HIDE_OVERLAY_WINDOWS` | Защита экранов приглашения/пропуска от tapjacking (API 31+) | При установке | — |

Не запрашиваются: геолокация, контакты, микрофон, хранилище (файлы — через SAF).

## Exported-компоненты
| Компонент | exported | Почему |
|---|---|---|
| `InviteActivity` | true | Единственная функциональная точка входа: `phonoteka://invite?token=[A-Za-z0-9_-]{8,64}`, открывает только регистрацию |
| `MainActivity` | true | Только MAIN/LAUNCHER — без этого приложение нельзя запустить. Deep link `details` удалён |
| `TrackInviteActivity` | false | Внутренний экран, только явный intent |
| `PlaybackService` | false | Внутренний сервис |
