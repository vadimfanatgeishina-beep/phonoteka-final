# Этап 6 — ЛР13: восстановление после потери ключа AndroidKeyStore

Статус: код написан, **не компилировался** (нет Gradle/Android SDK/интернета).

## Проблема до этапа
- `AndroidKeystoreRefreshTokenStore.read()` на любую ошибку (включая временный сбой Keystore) молча стирал токен — выглядело как случайный выход.
- Пользователь не видел причины (смена биометрии, снятие блокировки, перенос на другое устройство).
- Биометрическое хранилище при отсутствии ключа падало с `IllegalStateException`, зашифрованный блоб оставался.

## Матрица восстановления
| Ситуация | Действие | Что видит пользователь |
|---|---|---|
| Устройство заблокировано | ничего не удалять | разблокировать |
| Добавлен отпечаток / новая биометрия | удалить ключ и блоб | «ключ сброшен — войдите заново» |
| Снята блокировка экрана | удалить ключ и блоб | то же |
| Ключа нет (сброс, перенос) | удалить блоб | «ключ не найден — войдите заново» |
| Повреждён шифртекст | удалить блоб | «сессия повреждена — войдите заново» |
| Временный сбой провайдера | ничего не удалять | «повторите попытку» |

## Проверка на устройстве
1. Войти, включить биометрию → добавить новый отпечаток в настройках → открыть ЛР13: карточка KEY_INVALIDATED, вход по паролю работает, новая биометрия включается.
2. Снять блокировку экрана → открыть приложение: карточка, токен удалён.
3. `adb shell run-as <pkg>` испортить `shared_prefs/phonoteka_lab13_refresh_store.xml` → CORRUPT_BLOB.
