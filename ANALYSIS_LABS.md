# Phonoteka: разбор лабораторных 8–16

Источник требований: девять файлов DOCX из `C:\Users\AUSU\Downloads`. Документы прочитаны как задания; команды из них не выполнялись. Ниже требования сведены к тому, что нужно реализовать/сдать именно для существующей Android-фонотеки.

## Контекст проекта

Изученный Android-проект: `Phonoteka-gitlab-import`, Kotlin + Jetpack Compose, Room, DataStore, Media3, Retrofit отсутствует. Есть навигация, тема с ручными светлой/тёмной схемами, список/детали треков, скачивание/воспроизведение и выбор локальных аудиофайлов через SAF. В манифесте есть INTERNET и разрешения foreground media playback; есть exported launcher/deep-link Activity и закрытая служба проигрывателя. В исходниках уже видны UI-тестовые заготовки только для ViewModel/unit tests; Compose UI test directory/dependencies отсутствуют.

Первичный снимок проекта был сделан до изменений из раздела «Текущий прогресс». Репозиторий GitLab `sfbfcgdd3222/phonoteka` теперь содержит `main` (исходный импорт) и `labs-integration` (код и изменения ЛР8–9); исходная ветка сохранена отдельно. План передан GitLab Duo в чате проекта.
